The funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. A small Node program writes exactly one line to `/output/entry.txt`:

> WARNING: Will reply 'k' to your three-paragraph message, leave you on read for a week, and later ask why you seem upset.

It reads like a real printed label ("WARNING:" up front), the joke is recognition — everyone has sent the "k", everyone has been left on read — and the turn lands in the last few words. One idea, no filler, 120 characters, deterministic: the same fixed line on every run, no network, no input, no randomness.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
